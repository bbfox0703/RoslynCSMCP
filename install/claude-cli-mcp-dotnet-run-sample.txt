# Windows 11 - Using dotnet run (Development mode)
# Replace the path with your actual RoslynCSMCP location

# Method 1: Using project directory (recommended)
claude mcp add roslyn-mcp --scope user --transport stdio --env DOTNET_ENVIRONMENT=Development --env LOG_LEVEL=Information -- dotnet run --project D:\Github\RoslynCSMCP\RoslynMcpServer

# Method 2: Using .csproj file path (alternative)
# claude mcp add roslyn-mcp --scope user --transport stdio --env DOTNET_ENVIRONMENT=Development --env LOG_LEVEL=Information -- dotnet run --project D:\Github\RoslynCSMCP\RoslynMcpServer\RoslynMcpServer.csproj

# Method 3: Production mode with dotnet run
# claude mcp add roslyn-mcp --scope user --transport stdio --env DOTNET_ENVIRONMENT=Production --env LOG_LEVEL=Information -- dotnet run --project D:\Github\RoslynCSMCP\RoslynMcpServer -c Release

# Note:
# - The --project parameter should point to the PROJECT DIRECTORY or .csproj file
# - Do NOT point to bin\Debug\net10.0\ - that's the output directory, not the project
# - Use absolute paths (e.g., D:\Github\RoslynCSMCP\...) not relative paths
# - dotnet run will automatically build if needed (slower startup than using .exe)
# - For faster startup, use the .exe method (see claude-cli-mcp-exe-server-sample.txt)
